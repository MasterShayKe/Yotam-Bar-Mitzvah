# 🏎️ המירוץ למיליון — חידון בר מצווה

חידון אינטראקטיבי בסגנון "המירוץ למיליון" לבר מצווה.
האחיין עובר 32 תחנות (זיהוי לוגואים רשמיים, שיוך דגם→יצרן, מדינת מקור וידע) —
ובסוף זוכה ב**כרטיס רכבת סודי** שמפנה אותו לפגישה איתך.
🤫 **שים לב:** היעד הסופי נשאר מסתורי בכוונה — כדי לא לחשוף את ההפתעה!

## איך מריצים?

זה אתר סטטי — אין צורך בהתקנות.

- **הכי פשוט:** פתח את הקובץ `index.html` בדפדפן (לחיצה כפולה).
- **על הטלפון:** העלה את התיקייה ל-GitHub Pages (ראה למטה) ושלח לילד קישור.

### העלאה ל-GitHub Pages (חינם, נפתח מכל טלפון)
1. בריפו ב-GitHub: `Settings` → `Pages`.
2. תחת *Build and deployment* בחר `Branch` והענף שבו הקבצים, תיקייה `/ (root)`.
3. שמור — תוך דקה תקבל קישור כמו `https://<user>.github.io/<repo>/`.

## ✏️ מה צריך לערוך לפני האירוע

הכל נמצא בקובץ אחד: **`js/config.js`**

| שדה | מה זה |
|------|-------|
| `childName` | שם חתן בר המצווה |
| `questionsToWin` | כמה תשובות נכונות צריך כדי לזכות (ברירת מחדל 22 מתוך 32) |
| `secondsPerQuestion` | ⏱️ כמה שניות לכל שאלה (ברירת מחדל 20). כשנגמר הזמן עוברים הלאה — לא נפסלים |
| `ticket.from` | מי פוגש את החוגג בתחנה |
| `ticket.station` | **תחנת הרכבת שבה נפגשים** — חובה למלא! |
| `ticket.date` / `ticket.time` | תאריך ושעת המפגש |
| `ticket.secretMessage` | הודעה אישית על הכרטיס |

## ➕ לשנות שאלות

ערוך את **`js/questions.js`**. כל שאלה היא אובייקט עם:
`type` (`logo`/`text`), `logo` (שם מתוך `js/logos.js`), `mode`, `prompt`, `options`, `answer` (אינדקס מ-0), ו-`hint`.

**אתגרי לוגו (`mode`)** — הופכים את זיהוי הסמל למאתגר:
- `"zoom"` 🔍 — זום-אין קיצוני, רואים רק שבריר מהלוגו
- `"silhouette"` 🌑 — רק הצללית השחורה (בלי רמז צבע)
- `"blur"` 🌫️ — מטושטש ונשאר מטושטש עד לתשובה
- `"missing"` ❓ — חלק גדול מהלוגו מוסתר
- `"rotate"` 🔄 — הלוגו מוצג הפוך
- `"full"` — הלוגו המלא (קל)

ניתן **לשלב** מצבים ברווח, למשל `"zoom silhouette"` (שבריר שחור ומוגדל — הכי קשה).
בנוסף, ההיסחים (תשובות שגויות) הם מאותה משפחה/מדינה/צורה כדי להקשות.
על תשובה נכונה הלוגו המלא נחשף לרגע כ"פרס". 🎉

**הלוגואים מדויקים ורשמיים** — מבוססים על [Simple Icons](https://simpleicons.org)
(בצבע המותג הרשמי), משובצים ישירות בקוד (`js/logos.js`) כך שעובדים גם בלי אינטרנט.
מרצדס צויר ידנית (לא קיים ב-Simple Icons), ואלפא רומיאו משובץ כתמונה רשמית.

הלוגואים הזמינים: BMW, מרצדס, אאודי, פולקסווגן, טויוטה, טסלה, אלפא רומיאו, ניסאן,
הונדה, יונדאי, קיא, מאזדה, סובארו, מיצובישי, פרארי, למבורגיני, פורשה, פורד, שברולט,
רנו, פיג'ו, סיטרואן, אופל, וולוו, פיאט, ג'יפ, סקודה, סיאט, סוזוקי.

> רוצה לוגו חדש? אם יש לו קובץ ב-Simple Icons, הוסף את שמו לסקריפט ההורדה והרץ מחדש.
