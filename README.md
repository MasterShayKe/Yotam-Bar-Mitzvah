# 🏎️ המירוץ למיליון — חידון בר מצווה

חידון אינטראקטיבי בסגנון "המירוץ למיליון" לבר מצווה.
האחיין עובר 10 תחנות של זיהוי לוגואים ודגמי רכב — ובסוף זוכה ב**כרטיס רכבת סודי**
שמפנה אותו לפגישה איתך, ומשם לאירוע הדריפטים. 🛞💨

## איך מריצים?

זה אתר סטטי — אין צורך בהתקנות.

- **הכי פשוט:** פתח את הקובץ `index.html` בדפדפן (לחיצה כפולה).
- **על הטלפון:** העלה את התיקייה ל-GitHub Pages (ראה למטה) ושלח לילד קישור.

### העלאה ל-GitHub Pages (חינם, נפתח מכל טלפון)
1. בריפו ב-GitHub: `Settings` → `Pages`.
2. תחת *Build and deployment* בחר `Branch` והענף שבו הקבצים, תיקייה `/ (root)`.
3. שמור — תוך דקה תקבל קישור כמו `https://<user>.github.io/<repo>/`.

## ✏️ מה צריך לערוך לפני האירוע

הכל נמצא בקובץ אחד: **`js/config.js`**

| שדה | מה זה |
|------|-------|
| `childName` | שם חתן בר המצווה |
| `questionsToWin` | כמה תשובות נכונות צריך כדי לזכות (ברירת מחדל 7 מתוך 10) |
| `ticket.station` | **תחנת הרכבת שבה נפגשים** — חובה למלא! |
| `ticket.date` / `ticket.time` | תאריך ושעת המפגש |
| `ticket.secretMessage` | הודעה אישית על הכרטיס |
| `ticket.secretCode` | קוד סודי שהילד מראה לך בתחנה (אימות) |

## ➕ לשנות שאלות

ערוך את **`js/questions.js`**. כל שאלה היא אובייקט עם:
`type` (`logo`/`text`), `logo` (שם מתוך `js/logos.js`), `prompt`, `options`, `answer` (אינדקס מ-0), ו-`hint`.

הלוגואים הזמינים נמצאים ב-`js/logos.js`:
BMW, מרצדס, אאודי, פולקסווגן, טויוטה, טסלה, פרארי, פורשה, ניסאן, הונדה, למבורגיני, מאזדה, סובארו, פורד, שברולט.

